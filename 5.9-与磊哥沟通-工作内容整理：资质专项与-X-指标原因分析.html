工作内容整理：资质专项与 X 指标原因分析

1. 我的当前工作定位

我目前主要负责的是 资质专项。

资质专项属于广告审核中的重点专项之一，也是 X 指标中的头部问题之一。MT 提到，在 X 指标的头部标签里，超广审、资质、侵权等标签都排在前面，如果要继续把 X 指标往下压，这些头部问题需要持续解决。

除了资质专项本身，MT 还希望我通过分析 X 指标变化原因，快速理解广告审核业务、模型能力、规则体系、行业客户分布和样本特征。

也就是说，我现在的工作可以分成两条线：

  1. 主线工作：资质专项

    • 理解资质审核规则；
    • 分析资质类违规样本；
    • 找出模型在资质识别上的能力缺口；
    • 推动资质专项能力优化。

  2. 业务学习与能力建设：X 指标原因分析

    • 通过 Adata 数据平台看 X 指标变化；
    • 下钻异常标签和具体样本；
    • 从行业、客户、素材、规则、人审、模型能力等维度分析原因；
    • 建立模型产品的日常问题归因能力。

为什么要分析 X 指标变化原因

MT 交代我分析 X 指标变化原因，主要有几个目的。

3.1 找出 X 指标上涨的具体原因

看板只能告诉我们：

  • 今天 X 指标涨了；
  • 哪些标签涨了；
  • 哪些标签环比涨幅大；
  • 哪些标签绝对量靠前。

但是看板本身不能直接告诉我们：

  • 为什么涨；
  • 是模型问题还是规则问题；
  • 是新素材还是旧素材；
  • 是某个行业在涨还是某几个客户在刷；
  • 是审核尺度变化还是人审口径问题。

所以需要模型产品继续接手分析，把“数据异常”转成“具体原因”。

3.2 判断是不是模型能力问题

MT 说“能力”基本可以理解为“模型”。

当某个标签上涨时，需要判断：

  • 是模型没拦住；
  • 是模型之前没见过这种素材；
  • 是模型没有学习过新的判罚标准；
  • 是模型尺度放得太松；
  • 是新玩法、新素材导致模型泛化不足；
  • 还是其实不是模型问题，而是规则或人审问题。

分析清楚之后，下一步才能推动模型优化，避免 X 指标继续上涨。

3.3 找到头部问题，推动长期治理

有些标签可能涨幅很夸张，但基数很小。
有些标签涨幅没那么夸张，但绝对量很大，对 X 指标贡献更高。

所以分析时不能只看“涨了多少倍”，还要看“绝对量级”。

MT 提到，超广审、资质、侵权等都是头部问题。
如果要长期把 X 指标压下来，就要持续解决这些头部标签。

资质专项和 X 指标治理是有关联的，因为资质本身就是 X 指标中的重点标签之一。

3.4 通过真实样本快速理解业务

MT 让我要实际看素材、实际看原因。
因为只看指标很抽象，只有看具体样本，才能理解：

  • 各行业在投什么广告；
  • 广告主怎么表达功效、资质、权益、诱导信息；
  • 模型为什么拒不了；
  • 人审为什么这么判；
  • 规则和模型判断之间有什么差异；
  • 哪些行业、客户、素材类型是高风险来源。

所以分析 X 指标变化原因，也是在帮我快速理解广告审核业务。

4. MT 交代的分析思路

MT 给出的整体分析逻辑是：

看 X 指标变化→ 找到异常上涨标签→ 下钻具体样本→ 看行业、客户、素材、规则、人审、模型原因→ 内部对齐分析逻辑→ 推动模型/规则/策略优化

5. 具体应该怎么分析 X 指标

5.1 第一步：看 X 指标整体变化

先在 Adata 数据平台看 X 指标：

  • 今日 X% 是多少；
  • 是否超过 3% 目标；
  • 相比昨天/上周期是上涨还是下降；
  • 环比变化是多少；
  • 哪些标签贡献了上涨。

重点关注两类标签：

  1. 绝对量大的头部标签
    • 例如超广审、资质、侵权；
    • 这类标签对整体 X 指标贡献大；
    • 适合做长期治理。
  2. 环比涨幅异常的标签
    • 例如某个标签突然涨 10 倍、100 倍；
    • 这类标签可能出现新风险、新素材、新客户刷量；
    • 适合做日常异常分析。

5.2 第二步：进入复审明细看具体样本

MT 提到的路径是：

Adata → 元素叉乘标签粒度复审明细

操作方式：

  1. 进入“元素叉乘标签粒度复审明细”；
  2. 把对应的标签 ID 拖到筛选区；
  3. 选择时间范围，比如昨天、近几天或更长周期；
  4. 查看该标签下复审拒绝的具体 TID；
  5. 如果是视频素材，可以看审核员打的是哪一帧违规；
  6. 结合行业、客户等维度继续下钻。

5.3 第三步：按行业维度下钻

看这个标签上涨是否具有行业集中性。

需要看：

  • 哪些一级行业贡献最多；
  • 哪些二级行业贡献最多；
  • 是否某一个二级行业突然暴涨；
  • 是否某类行业集中出现类似违规素材。

分析问题：

这个标签上涨，是全行业普遍上涨，还是集中在某几个行业？

如果集中在某个行业，就继续把该行业作为筛选条件，再看该行业下的具体素材为什么被拒。

5.4 第四步：按客户维度下钻

看是否由少数客户集中贡献。

需要看：

  • 是否只有一两个客户贡献大量曝光；
  • 是否某几个客户集中上传类似素材；
  • 是否疑似恶意客户在刷素材；
  • 是否广告主发现审核尺度放松后，开始试探边界；
  • 是否存在“先刷素材测试，再正式投放”的行为。

分析问题：

这个标签上涨，是行业整体问题，还是少数客户集中刷量导致？

5.5 第五步：看具体素材

这是最关键的部分。

需要直接看被复审拒绝的素材，判断：

  • 素材是什么形式：图片、视频、落地页、文案等；
  • 违规点在哪里；
  • 是不是新素材；
  • 是不是新表达方式；
  • 是不是模型之前没见过的玩法；
  • 是否和历史违规样本相似；
  • 视频违规点出现在哪一帧；
  • 复审拒绝是否合理。

分析问题：

这些被拒素材到底为什么违规？模型为什么没有在前置环节拦住？

5.6 第六步：从规则角度判断

作为产品，需要站在规则角度判断：

  • 这些素材按规则到底应不应该拒；
  • 人审拒绝是否合理；
  • 是否存在边缘样本；
  • 是否是规则表达不清；
  • 是否是规则最近有变化；
  • 是否模型判断和人审判断不一致；
  • 是否需要找规则同学对齐口径。

分析问题：

这是模型没识别，还是规则/人审口径本身存在不一致？

5.7 第七步：从模型能力角度判断

如果确认样本确实应该拒，就要进一步判断模型为什么没拦住。

可能原因包括：

  1. 模型未识别
    • 素材违规点明显，但模型没有召回。
  2. 新素材/新玩法
    • 模型之前没见过类似表达；
    • 训练样本中缺少这类 case。
  3. 新判罚标准
    • 规则或审核尺度变化后，模型还没有学习新标准。
  4. 模型尺度过松
    • 为了降低误伤，模型放松后导致漏放增加。
  5. 行业/客户分布变化
    • 某些行业或客户突然大量投放相关素材，超过模型原有覆盖能力。

分析问题：

这个问题是否可以通过模型补样本、调阈值、重训、规则兜底等方式解决？

5.8 第八步：内部对齐

MT 明确说，当前阶段不用直接在大群里发报告。

我应该先：

  • 自己看样本；
  • 形成初步判断；
  • 先和 MT 内部对齐；
  • 也可以问佳晨，因为佳晨之前做过类似分析；
  • 对齐后再决定是否需要在群里同步或推动后续动作。
